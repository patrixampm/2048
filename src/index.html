Welcome to 2048

Use the arrow keys to move tiles on a 4x4 grid. When two tiles with the same number touch, they merge into one with their sum. The goal is to create a tile with the value of 2048.

Controls

  • ↑ Up Arrow: Move tiles up
  • ↓ Down Arrow: Move tiles down
  • ← Left Arrow: Move tiles left
  • → Right Arrow: Move tiles right

Rules

  • The game starts with two tiles (2 or 4) randomly placed on the grid
  • After each move, a new tile (2 or 4) appears in a random empty spot
  • Tiles merge when they have the same value and collide
  • Your score increases by the value of each merged tile
  • You win when you create a 2048 tile
  • You lose when the grid is full and no moves are possible
